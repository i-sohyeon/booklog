# BookLog 정보 구조 (IA)

## 내비게이션 원칙
- **모바일(<1024px)**: 상단 앱바(로고 · 샘플 데이터 배지 · 프로필) + 하단 탭 5개
  - 홈 / 서재 / 검색 / 피드 / 마이
  - 통계 · 모임 · 설정 등 하위 기능은 홈 · 마이에서 진입하는 별도 화면
- **데스크톱(≥1024px)**: 좌측 사이드바에 전체 메뉴를 그룹으로 노출
  - 나의 독서: 홈, 내 서재, 도서 검색, 독서 통계
  - 함께 읽기: 친구 피드, 독서 모임
  - 하단: 프로필(마이페이지)
- 상세 화면(도서 상세)은 모바일 앱바를 숨기고 자체 뒤로가기 버튼을 사용

## 화면 맵 & 라우트

| # | 화면 | 경로 | 1차 상태 | 주요 기능 |
|---|------|------|---------|-----------|
| 1 | 홈 대시보드 | `/` | ✅ 구현 | 인사말, 읽는 중(진도 기록), 올해 목표·이번 달 현황·캘린더, 최근 기록, 발견 |
| 2 | 내 서재 | `/library?status=&sort=&view=` | ✅ 구현 | 상태 탭(전체/읽는 중/읽고 싶은/완독/중단), 정렬, 격자/목록 |
| 3 | 도서 검색 | `/search?q=` | ✅ 구현 (샘플 검색) | 디바운스 검색, 최근 검색어, 추천 키워드, 장르, 서재 담기 |
| 4 | 도서 상세 | `/books/:bookId` | ✅ 기본 구현 | 서지 정보, 서재 담기, 상태 변경, 진도 기록, 별점, 삭제, 메모 목록 |
| 5 | 독서 기록 작성/수정 | `/books/:id/notes/new?kind=`, `/books/:id/notes/:noteId`, `/books/:id/review` | ✅ 2차 | 메모·문장(쪽수), 별점·리뷰, 공개 범위, 이탈 방지, 삭제 |
| 5-1 | 나의 기록 | `/notes` | ✅ 2차 | 전체 메모·문장 모아보기, 종류 필터, 검색 |
| 6 | 독서 통계 | `/stats?view=year\|month\|history` | ✅ 2차 | 연간(요약·목표 페이스·월별 차트·연간 캘린더·장르·올해의 서재), 월간(일별 차트·캘린더·이달의 책), 활동 히스토리 |
| 7 | 친구 피드 | `/feed` | 🕓 3차 | 친구 활동, 좋아요/댓글, 친구 검색·초대 |
| 8 | 친구 프로필 | `/users/:handle` | 🕓 3차 | 친구 서재 방문, 공개 기록 |
| 9 | 독서 모임 | `/clubs`, `/clubs/:clubId` | 🕓 4차 | 모임 생성·참여, 함께 읽을 책, 토론, 공동 목표 |
| 10 | 마이페이지 | `/me` | ✅ 2차 | 프로필, 목표, 계정(로그인 상태·로그아웃·비밀번호 변경), 기록 옮기기(기기↔계정), 데이터 관리 |
| 11 | 로그인/회원가입 | `/login`, `/signup`, `/reset-password`, `/account/password` | ✅ 2차 (Supabase 설정 필요) | 이메일 로그인·가입·메일 인증 안내·비밀번호 재설정 |

🕓 화면은 "준비 중" 안내 페이지로 연결되며, 동작하지 않는 UI를 흉내내지 않습니다.

## 홈 대시보드 우선순위
1. **인사말 + 오늘의 한 줄** — 연속 독서일 기반 동기 부여
2. **지금 읽는 중** — 가장 최근 활동한 책을 히어로로, 나머지는 컴팩트 목록. 진도 기록을 1탭으로.
3. **올해의 독서** — 목표 달성률(링) + 이번 달 쪽수/독서일/완독 + 월간 캘린더 (데스크톱에서는 우측 고정)
4. **최근 기록** — 메모·문장 3개
5. **발견** — 서재에 없는 책 추천 (샘플)

## 데이터 모델 (src/types/book.ts)
- `Book` — 서지 정보 (외부 API에서 수급)
- `LibraryEntry` — 사용자별 독서 상태(status, 시작/완료일, currentPage, rating, review)
- `ReadingSession` — 날짜별 읽은 쪽수 (캘린더·통계의 원천)
- `ReadingNote` — 메모 / 인상 깊은 문장 (+ `visibility` 공개 범위)
- `ReadingGoal` — 연간 목표 권수

진도를 올리면 증가분이 오늘의 `ReadingSession`으로 기록되어 캘린더와 통계에 즉시 반영됩니다.
