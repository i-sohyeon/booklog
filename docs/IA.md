# BookLog 정보 구조 (IA) — 리디자인 v4

> 책을 위한 "시네필 감성" 기록·커뮤니티 앱.
> 진도·쪽수 기록은 하지 않는다. 다 읽은 책에 **별점(0.5, 필수)** 과 선택 기록(한 줄 평·감상·문장·장소·태그 등)을 남기고,
> 다른 사람들의 후기·취향을 구경하고, 독서모임으로 함께 읽는다.

## 내비게이션
- **하단 탭 5개 (모바일)**: 홈 / 발견 / 커뮤니티 / 서재 / 마이
  - 기준: 개인화된 콘텐츠는 **홈**, 누구에게나 같은 콘텐츠는 **발견**
  - 상세 화면에서도 해당 탭이 활성 표시됨 (`/books`·`/lists` → 발견, `/clubs` → 커뮤니티)
- **플로팅 버튼 (모바일, 탭 바 위 오른쪽 16px)**
  - 홈 · 발견 · 서재: "+" 책 기록
  - 커뮤니티: 같은 자리에 "글쓰기" (독서모임 세그먼트에서는 "모임 만들기")
  - 마이·상세·작성 화면: 숨김
  - 아래로 스크롤하면 숨기고, 위로 스크롤하면 다시 표시
- **데스크톱(≥1024px)**: 좌측 사이드바 (5개 메뉴 + "책 기록하기" + 프로필), 플로팅 버튼 없음

## 화면 & 라우트

| 탭 | 화면 | 경로 | 주요 내용 |
|----|------|------|-----------|
| 홈 | 홈 | `/` | 인사말, 취향 기반 오늘의 추천 한 권(큰 표지·한 줄 소개), 읽는 중(표지·제목 가로 스크롤), 친구들이 다 읽은 책, 참여 중인 모임 다음 일정 |
| 발견 | 발견 | `/discover?q=` | 검색, 베스트셀러 차트(종합·소설·에세이·인문·자기계발), 지금 화제인 후기, 큐레이션 리스트 |
|  | 책 상세 | `/books/:id` | 표지, 저자, 줄거리, 평균 별점·분포, 후기(공감순/최신순), 읽고 싶어요 / 읽는 중 / 다 읽었어요, 내 기록, 리스트에 담기 |
|  | 리스트 상세 | `/lists/:id` | 리스트 책 목록, 공감 / (내 리스트) 책 추가·빼기·삭제 |
| 커뮤니티 | 게시판 | `/community` | 세그먼트 게시판 \| 독서모임. 자유 이야기 · 책 추천 요청 · 문장 공유, 책 태그, 좋아요·댓글, 스포일러 가리기 |
|  | 독서모임 | `/community?tab=clubs` | 모집 중 / 참여 중, 모임명·책 표지·일정·인원(6/10명)·참여 (`/clubs`는 여기로 이동) |
|  | 글 상세 · 글쓰기 | `/community/:id`, `/community/new` | 본문·댓글, 종류·(문장 공유) 문장·책 태그·스포일러 |
|  | 모임 상세 · 만들기 | `/clubs/:id`, `/clubs/new` | 다음 온라인 모임·입장하기(시작 10분 전~종료), 주차별 범위, 참여자, 토론 스레드 / 모임 생성 |
| 서재 | 서재 | `/library?status=&view=&tag=&rating=` | 올해 결산 카드, 상태 필터(다 읽은 책·읽는 중·읽고 싶어요), 캘린더 \| 리스트, 태그·별점 필터 |
|  | 문장 모아보기 | `/library/quotes` | 저장한 문장(텍스트·사진)만 카드로, 책별 보기 |
|  | 기록 자세히 쓰기 | `/library/:bookId/edit` | 상태, 별점(필수)·완독일·회독, 한 줄 평, 긴 감상, 문장, 장소·계기, 태그 — 항목별 공개/비공개(기본 비공개) |
| 마이 | 마이 | `/me` | 프로필, 팔로워/팔로잉, 내 후기 · 내 리스트 · 참여 모임, 설정 |
|  | 설정 | `/me/settings` | 계정(로그인), 기록 옮기기(기기↔계정), 데이터 관리 |
| — | 인증 | `/login`, `/signup`, `/reset-password`, `/account/password` | Supabase Auth (설정 필요) |

이전 주소: `/search` → 발견, `/stats` → 서재, `/notes` → 문장 모아보기, `/clubs` → 커뮤니티 독서모임.

## 기록 방식
1. 플로팅 "+" → 바텀시트에서 책 검색 (책 상세에서는 생략)
2. 상태: 다 읽었어요 / 읽는 중 / 읽고 싶어요
3. 다 읽었어요 → 별점(0.5 단위, 필수) + 한 줄 평(선택, 80자) + 완독일(기본 오늘) → 서재에 저장
4. "저장하고 자세히 쓰기" 또는 책 상세의 "기록 자세히 쓰기" → 기록 편집 화면

"읽는 중"은 상태만 표시하고 진도는 받지 않습니다.
