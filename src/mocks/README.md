# mocks — 샘플(임시) 데이터

이 폴더의 데이터는 **실제 데이터가 아닙니다.** Supabase / 도서 검색 API 연결 전까지
UI 개발과 시연을 위해서만 사용합니다.

- `catalog.ts` — 도서 검색 API를 대신하는 샘플 도서 목록 (서지 정보는 참고용이며 정확하지 않을 수 있음)
- `library.ts` — 내 서재(상태·별점·한 줄 평·문장·태그·장소·회독·공개 설정)의 초기 샘플 상태 (오늘 기준 상대 날짜)
- `social.ts` — 가상의 사용자·후기·커뮤니티 글·독서모임·큐레이션 리스트·베스트셀러·평점 분포
- `user.ts` — 로그인 연결 전 임시 사용자

후기 문구는 샘플용으로 작성한 감상이며 책 본문 인용이 아닙니다. 문장 샘플은 저작권이 만료된 고전(『어린 왕자』·『데미안』·『노인과 바다』·『위대한 개츠비』)에서 샘플용으로 직접 옮긴 짧은 구절만 사용합니다.

앱 화면에서는 상단의 **"샘플 데이터"** 표시로 구분되며, 마이 › 설정 › 데이터 관리에서 샘플 데이터를 비우거나 다시 불러올 수 있습니다.
실제 API를 연결할 때는 `src/services/*` 의 구현만 교체하면 됩니다.
