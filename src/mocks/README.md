# mocks — 샘플(임시) 데이터

이 폴더의 데이터는 **실제 데이터가 아닙니다.** Supabase / 도서 검색 API 연결 전까지
UI 개발과 시연을 위해서만 사용합니다.

- `catalog.ts` — 도서 검색 API를 대신하는 샘플 도서 목록 (서지 정보는 참고용이며 정확하지 않을 수 있음)
- `library.ts` — 내 서재 / 독서 기록 / 메모의 초기 샘플 상태 (오늘 날짜 기준 상대 날짜로 생성)
- `user.ts` — 로그인 연결 전 임시 사용자

앱 화면에서는 상단의 **"샘플 데이터"** 표시로 구분되며, 마이페이지에서 샘플 데이터를 비우거나 다시 불러올 수 있습니다.
실제 API를 연결할 때는 `src/services/*` 의 구현만 교체하면 됩니다.
